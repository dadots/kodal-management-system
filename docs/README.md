# Kodal Management System

A modular, multi-tenant Business Management Platform built with Laravel, Next.js, Electron, and PostgreSQL.

## Features

- Multi-tenancy
- Inventory Management
- Point of Sale (POS)
- Purchasing
- Warehouse Management
- Reports
- Offline-first desktop application
- Role & Permission Management

## Tech Stack

- Laravel 12
- Next.js 15
- Electron
- PostgreSQL (Neon)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Redux Toolkit
- React Query
